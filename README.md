# Synaps

VR-native search and spatial knowledge system for Meta Quest 3.

## Concept
Synaps transforms search from a list of links into a spatial, persistent and connected knowledge workspace.

Users can:
- Search using hands-only interaction
- Explore results as spatial cards
- Save important information as nodes
- Build a personal knowledge graph with semantic relations

## Current Focus
- VR-native text input research (hands-only)
- Spatial search interface
- AI-assisted summarisation and clustering
- Persistent knowledge graph
